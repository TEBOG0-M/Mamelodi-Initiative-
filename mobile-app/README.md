# Mamelodi Initiative — Android

Phase 1 foundation for the Work Integrated Learning 3B Android application.

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- ViewModel
- Android Studio

## Phase 1
- Project foundation
- Mamelodi Initiative colour palette and theme
- Main and bottom navigation
- Route definitions
- Reusable UI components
- Programme, news and volunteer models
- Sample data
- Volunteer application ViewModel
- Placeholder routes for all planned screens

Open the `MamelodiInitiative` folder in Android Studio and sync Gradle.
